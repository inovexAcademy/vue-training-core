# Exercise 02 Components

The goal of this exercise is to create your own components and display them on the home page.

## 📝 Tasks

- [ ] Create a Vue component called `ProductCard` with arbitrary title, description, price, and "Add to cart"-button
  > - [ ] 💪 Bonus challenge: Use `OnyxHeadline`, `OnyxCard`, and `OnyxButton` where possible!
- [ ] Create another component `ProductList` with a title "Available Products" that renders two `ProductCard` components
- [ ] Display `ProductList` on the home page (see `HomeView`)
